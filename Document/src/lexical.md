## 注释

注释有两种形式：

- 行注释：`//` 到行尾。
- 块注释：`/* ... */`，可跨行，**不支持嵌套**；未闭合的块注释是编译错误（E1004）。

## 关键字

Lis 共有 33 个关键字：

| 类别 | 关键字 |
|---|---|
| 声明 | `struct` `enum` `trait` `impl` `fn` `let` `pub` `impt` |
| 控制流 | `if` `else` `while` `for` `in` `match` `ret` `break` `continue` |
| 引用/借用 | `self` `mut` `as` `move` |
| 类型关键字 | `i8` `i16` `i32` `i64` `f32` `f64` `bool` `char` `void` `never` |
| 布尔字面量 | `true` `false` |

说明：

- 返回关键字是 **`ret`**（非 `return`）。
- `impt`（import）导入模块，见[模块与导入](./declarations.md)。模块名是普通标识符，
  **不能是关键字**（字符分类模块名为 `chars`，`impt char` 会报「expected module name」）。
- `move` 关键字的设计语义为「每次使用时在使用处移动构建」（类似 Rust 的相关语法），
  **未实现**；当前全局 `let move x = ...` 可解析但无效果，见[已知限制](./limitations.md)。
- `never` 是 uninhabited（bottom）类型关键字，见[类型系统](./types.md)。
- 无 `const` 关键字；无 `<<`/`>>` 运算符 token（见[运算符](./operators.md)）。

## 标识符

标识符由字母/下划线开头，后跟字母、数字或下划线。**同一作用域内禁止隐式覆盖**
（shadowing）：`let x = 1; let x = 2;` 是编译错误（E3003 系「already exists in this scope」）。

## 字面量

### 整数字面量

十进制 `[0-9]+` 或十六进制 `0x`/`0X` 加十六进制数字（`0x1F`、`0xdead_beef`）；两种进制都允许
`_` 作为**数字之间**的分隔符（`1_000_000`、`0x4002_0000`），它只是给人读的，取值时会被去掉。
无前缀、无后缀（没有八进制/二进制写法）。类型为 `i32`；超出 `i64` 范围的整数字面量是错误。

`0x` 后面没有数字、`0x_1`（分隔符不在两位数字之间）、`1_`（分隔符后没有数字）都是词法错误
（E2016），但错误之后 token 仍然发出，词法流不会错位。

```lis
42          // i32
0           // i32
0x4002_0000 // 1073872896：外设地址的写法（见[内存映射 IO](./mmio.md)）
```

**注意值域**：无类型标注的整数字面量是 `i32`，十六进制也一样——`0xdead_beef as i64` 会先按
`i32` 截断再拓宽（与十进制字面量同一条已知限制，见[已知限制](./limitations.md)）。

**没有负数字面量 token**：`-5` 是前缀运算符 `-` 加字面量 `5`。解析器会把 `-<字面量>` 折叠成
负值，因此要求字面量的全局初始化器可以写 `let g = -5;`（见[运算符](./operators.md)）。

### 浮点字面量

`[0-9]+ '.' [0-9]+ ([eE][+-]?[0-9]+)?` 或 `[0-9]+ [eE][+-]?[0-9]+`。类型为 `f64`。

```lis
3.14        // f64
1e10        // f64
2.5e-3      // f64
```

注意：`3.` 被词法为整数 `3` 加 `.`（成员访问）；`.5` 不是合法浮点字面量。

### 字符字面量

`'x'`，单字符或一个转义。类型为 `char`（运行时按 `i32` 处理）。

转义：`\n` `\t` `\r` `\'` `\\` `\0`。未知转义按原样保留（`'\q'` 是两个字符，报错）。
多字符字面量（`'ab'`）是错误。无 `\x`/`\u` 转义。

### 字符串字面量

`"..."`，转义：`\n` `\t` `\r` `\0` `\"` `\\`。支持多行字符串；UTF-8 字节原样通过。
**字符串字面量的类型是 `&i8`**（裸指针，指向静态存储的 C 字符串）——编译器会给出一次性警告：
「string literals are modelled as &i8 (raw pointer); a proper string type is not implemented yet」。

### 布尔字面量

`true` / `false`，类型 `bool`。

## 运算符与分隔符

- 算术：`+ - * / %`
- 比较：`== != < > <= >=`
- 逻辑：`&& ||`
- 位：`& ^ |`（`<<`、`>>` 无 token，见[运算符](./operators.md)）
- 赋值：`=`
- 其他：`!`（仅用于 `!=`）、`?`（**后缀**错误传播运算符，见[表达式](./expression.md)）
- 分隔符：`{ } ( ) , : ; . :: -> => & [ ]` 及属性起始 `#[`

`?` 现在是真正的 token（此前是「Unknown character」词法错误）。它只作后缀用，
没有二元优先级。

`&` 有三种角色：前缀借用（`&x`/`&mut x`）、中缀位与（`a & b`）、类型引用（`&T`/`&mut T`）。
