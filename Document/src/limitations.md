# 已知限制与路线图

<!-- grammar_name: limitations, search_name: 已知限制,路线图,未实现 -->

本页汇总语言当前未实现/待定的部分。标注「规范决策」的语义已定案；
标注「待定」的取舍尚未定案。

## 已定案的规范决策（2026-08-12）

| 决策 | 内容 |
|---|---|
| `let x;` 无初始化 | **已实现**（2026-09-13）：Move 绑定必须有初始化器（E3012）；Copy 绑定的读取/借用/移动前必须定值（E3011，流敏感、跨分支取与、循环保守）；不做字段级定值 |
| 默认参数 `fn f(a: i32 = 5)` | **移除**：死语法（解析后全阶段忽略），现在直接报错 |
| `#[i_know]` 属性 | **已实现**：语句前属性，窄化 cast 错误降级为警告 |
| `move` 关键字 | 设计语义：**每次使用时在使用处移动构建**（类似 Rust 相关语法）；**未实现**，当前全局 `let move x = ...` 可解析但 `move` 标志无效果 |

## 未实现的语言特性

### 语法面

- ~~**一元运算符** `-` `!` `~`~~：**已实现**（2026-09-19）——`-` 整数/浮点、`!` 仅 bool、
  `~` 仅整数，`+x` 解析后擦除；**可重载的 `Neg`/`Not` trait 仍未开放**，见[运算符](./operators.md)。
- **`^` `<<` `>>` 运算符**：无 token；仅方法 `bitxor`/`shl`/`shr` 可调用。
- **函数类型语法**：函数指针存在（间接调用可用），但无类型语法。
- ~~**复合赋值**~~：**已实现**（2026-09-19）`+= -= *= /= %=`，目标是位置且只求值一次；
  **重载了二元运算符的类型暂不支持**（原语与下标运算符可用），见[运算符](./operators.md)。
- **`if` 表达式**：if 是语句；值产生用 match 表达式。
- **属性**：仅 `#[i_know]` 一种；无其它属性语法。
- ~~**解引用运算符** `*x`~~：**已实现**（2026-09-19），只作用于引用，见[表达式](./expression.md)。
- **闭包**、**字符串拼接**：无。
- ~~**数组重复字面量** `[v; N]`~~：**已实现**（2026-09-19）。

### 语义面

- **panic / never 类型**：**已实现**（2026-09-12）。内置 `panic(&i8) -> never` 写 stderr 后
  `abort()`；`never` 是 bottom 类型，可用作函数返回类型与变量类型（读取 `never` 变量是
  错误），`Option::unwrap` / `expect` 已提供（见[内置函数](./builtins.md)、[标准库](./stdlib.md)）。
  数组越界仍用 libc `abort()`。
- **引用模式匹配**（`match &opt`）：未实现。
- **返回借用追踪**：`to_cstr` 返回的借用编译器不追踪，调用方负责 owner 存活。
  `Vec::at_ref`/`at_mut`（2026-09-19）是同一类妥协，而且风险更大——**扩容会 `__free` 旧缓冲**，
  拿到引用之后再 `push` 就是 use-after-free（由调用方保证）。
- **堆的表示与边界**：**已实现**（2026-09-15）。堆缓冲是真正的裸指针类型 `*mut i8`
  （`String.data`），堆原语 `__alloc`/`__free`/`__memcpy`/`__strlen` 与裸指针索引、
  `__deref`/`__deref_mut` **只能在标准库内使用**（E3013/E3014），
  `&mut T` 恢复非 Copy 语义并配套隐式重借用，字段可见性 `pub` **由编译器强制**（E3015）。
- **指针仍然不做的事**（不安全核心的内部，逐条记录）：
  - 标准库**内部**的 `p[i]` 仍无越界检查（`Vec` 已把这条封在 `at`/`set` 里并做了检查，
    但直接的裸指针索引本身仍然不安全）；
  - `__free(p)` 之后继续用 `p` 不会被发现（没有 use-after-free 分析）；
  - 裸指针没有生命周期，`__deref` 出来的引用不参与悬垂返回追踪。
- **`read_line() -> &i8`**：仍指向编译器内部的 256 字节静态缓冲，下一次读会覆盖它；
  类型上写着共享引用，实际是可写全局——已知的别名妥协，未修。输入耗尽时返回空串
  （见[内置函数](./builtins.md)），空行与 EOF 不可区分。
- **未初始化读取拒绝**：**已实现**（2026-09-13）。Move 绑定必须有初始化器（E3012）；Copy 绑定
  允许 `let x;`，但使用前必须定值（E3011，流敏感、跨分支取与、循环保守）。
  **不做**字段级定值：对 `let x;` 绑定写字段 `x.f = 1;` 被拒绝。
- **`?` 的已知边界**：只作用于标准库 `result::Result`（自定义 Ok/Err 枚举不参与）；
  不支持 `Option`（`o?` 无意义，用 `match` 或 `unwrap_or`）；**没有**错误类型转换
  （`From`/`Into` 不存在，E 必须直接兼容）；不能在返回类型不是 Result 的函数里使用。
- **无上下文的泛型值**：`let x = Option::None;`（既无标注也无期望类型）取到的是类型
  **定义**（字段里还是裸 `T`），编译期以「cannot infer the generic argument(s) of 'Option'」
  报错——**不会**崩溃，也仍不做推断。同类错误：`get(Option::None)` 传给 `Option<i32>`
  形参、`let x: Option<i32> = Option::None;`、裸泛型类型 `fn f(o: Option)`。要显式给出
  类型实参或加标注（`Option<i32>::None` 需要带载荷的变体语法，单元变体目前只能靠标注/
  `ret` 期望类型推断）。
- **嵌套模式 / or 模式 / 字面量模式**：match 模式仅 `_`/单元变体/载荷绑定。
- **数组元素借用精度**：**已实现**（2026-09-19）。常量索引进 place 路径（`a[0]` 与 `a[1]`
  不相交），非常量索引仍用通配 `[*]` 保守拒绝。见[借用检查](./borrow.md)。
- **数组**：元素仅 Copy、禁引用、禁作参数/返回（用 `&[T; N]`）、尺寸 ≤ 1<<20。
  数组字面量 `[v; N]`（2026-09-19）在**全局**位置仍被拒绝——全局初始化器必须是一个字面量。
- **`*p` 参与借用检查**（2026-09-19）：解引用经别名表解析到所指位置，重借用会冻结指针，
  访问通过引用时豁免其派生链——详见[借用检查](./borrow.md)。仅剩两条边界：
  - 指针来源未知时（参数、被覆盖过的引用）只用「同一引用表达式 = 同一位置」判冲突，
    看不到与调用方变量的联系；
  - 只有**整个 pointee** 的写（`*p = v`）会析构被覆盖的旧值；`p.f = v` / `(*p).f = v` 仍然
    直接覆盖（既有行为，会漏一次析构）。
- **`&i8` 的 `==` 是内容比较**（2026-09-19）：两个 `&i8` 按 C 串比较，因此它们必须指向以 NUL
  结尾的缓冲；`&i8` 若来自 `&单个i8变量`，比较会读到缓冲之外。`<`/`>` 不支持（用 `str_cmp`）。
- **比较类 operator trait 的接收者是引用**（2026-09-19，**破坏性变更**）：`PartialEq`/`PartialOrd`
  声明为 `fn eq(self: &Self, other: &Self) -> bool`，实现必须写 `&Self`；按值签名的旧实现
  会在 trait 一致性检查里报「param 2 type mismatch」。算术类 trait（`Add` 等）仍按值。
- **`for` 的三种形态**（2026-09-19）：`for x in v` **借用**（`x: &T`）、`for x in move v`
  **消费**（`x: T`）、右值（`range(1,5)`）只能消费。两条边界：(a) 位置形态要求该类型有
  `iter()`（目前只有 `Vec<T>`），名字绑定的**纯迭代器**（`let r = range(1,5); for i in r`）报
  `struct 'iterator$Range' has no method 'iter'.`，要写 `for i in move r`；(b) 已经是引用的
  位置要写 `for x in *r`——**没有运算级自动解引用**。借用形态下循环体不能改动被借的集合
  （E4001，扩容会释放迭代器指着的缓冲）。
- **没有可变借用迭代（`iter_mut`）**（2026-09-19）：产出 `&mut T` 需要「返回借用 + 借用追踪」，
  而这套机制目前会被悬垂检查误判——`fn f(v: &mut Vec<T>) -> &mut Vec<T> { ret v; }` 报 E4001，
  方法里返回 `&mut self` 的重借用（`VecIterMut` 那种写法）报 E3002/E4001。就地改元素用下标
  循环 `while i < v.len() { v[i] = ...; i += 1; }`（下标运算符可用）。
- **定义类型与实例化类型是两种拼写**（2026-09-19）：`Vec`（定义，字段仍是裸 `T`）与 `Vec<T>`
  （实例化）在签名里是两个类型，写泛型返回类型要显式带上实参（`-> VecIter<T>`），裸名字会被
  当成定义。`CustomType::equals` 已对「定义 vs **用自身参数**实例化」放宽（`self: &Vec<T>`
  与字段 `Vec<T>` 相等），但**不**做一般的期望类型推断。
- **`let ... else` 只认 Option/Result**（2026-09-19）：与后缀 `?` 同一限制；`else` 之后是
  **表达式**（不是块，`else { ... }` 不合法），类型必须等于载荷类型（`never` 兼容）；
  全局定义不能用（全局初始化器必须是字面量）。
- **运行时条件 drop**：**已实现**（2026-09-15）。只在部分路径上被移出的值按 Rust 的 drop flag 语义处理：每个 drop 槽位带运行时所有权位，析构落在作用域末尾而不是分支边上。旧的静态边放置会提前释放（析构顺序可见，对借用检查不追踪的裸指针别名是 use-after-free），部分移动时还会双重释放。

### 语义取舍（保守关闭，防误报）

- 悬垂返回检查对无法判定来源的引用（Unknown）放行（漏报不误报）。
- 借用检查对复杂索引/解引用链保守（见[借用检查](./borrow.md)的已知边界）。
- OOM 不检查（`malloc` 失败即运行时崩溃）。

## 路线图

按可用性优先级：

1. ~~**panic/never 类型**：解锁 `unwrap`/`expect`/`Result`。~~ **已完成 2026-09-12**
   （`panic` + `never` + `Option::unwrap`/`expect`）。
2. ~~**编译期拒绝未初始化读取**（规范决策落地）。~~ **已完成 2026-09-13**
   （定值分析；同时落地 `Result<T, E>` 与后缀 `?` 错误传播）。
3. **`move` 语义实现**（用户定义：使用处移动构建）。
   - 注意：**移动语义本身已完整实现**（移动后使用 E3005、部分移动、借用冲突 E4004），
     未实现的只是 `move` **关键字**这一书写形式（`let move x = ...`，目前全局声明的 `move` 标志解析后无效果）。
4. ~~**Vec/堆集合**：基于 String 的裸指针堆机制扩展。~~ **已完成 2026-09-19**
   （`Source/Std/vec.lis`：`Vec<T>` + `Index`/`IndexMut` trait + `impl Drop`；
   配套编译器改动：`__sizeof`、带类型的 `__alloc<T>`、用户类型的下标运算符）。
   剩下的部分：
   - ~~**非 Copy 元素**（`Vec<String>`）~~：**已完成 2026-09-19**——`Vec<T>` 去掉 `T: Copy`，
     stdlib-only 内建 `__drop(x)` 在标准库内析构一个位置上的值，`clear`/`Drop` 逐元素析构、
     `at_ref`/`at_mut` 出借元素、`for` 靠游标记录已移出前缀以免二次析构；按值交出元素的
     `v[i]`/`get` 改成条件实现 `impl<T: Copy> ...`（impl 上的泛型约束此前解析后被丢弃，
     现在在调用点检查）。**非 Copy 数组元素**（`[String; 2]`）仍未做，数组继续要求元素 Copy。
   - `with_capacity` / `reserve`：扩容需要元素大小，而 `__sizeof` 要一个 T 的值
     （泛型体里没有），所以现在只能由 `push`/`insert` 的实参把大小带进来。
     ~~`iter()`~~：**已实现**（2026-09-19，`VecIter<T>` + `for x in v` 借用遍历，见
     [标准库](./stdlib.md)）；**`iter_mut()` 仍未做**（见下面的可变借用迭代）。
   - `Vec::new()` 仍要写类型实参（`Vec<i32>::new()`）：本语言不做期望类型推断，
     `let v: Vec<i32> = ...` 的标注不回推（与 `Option::None` 同一条规则）。
5. **数组精确索引路径**：允许不相交元素借用。
6. **extern/FFI 机制**：声明外部函数（codegen 已就绪）。
7. **String 增强**：格式化/拼接。
8. **引用模式 D4**：`match &opt`。
9. ~~**一元运算符**（`-`/`!`/`~`）、**复合赋值**（`+=` 等）、**`for` 默认借用**、
   **`let ... else`**~~：**已完成 2026-09-19**。剩下的：`Neg`/`Not`（一元运算符重载）、
   复合赋值用于重载类型、`iter_mut()`（可变借用迭代）、数组与自定义集合的 `iter()`。

每项实现前如有语义取舍，由语言设计者（用户）拍板后更新本手册。
