## 拷贝与移动（Copy vs Move）

类型的拷贝/移动属性是整个语言安全模型的基础：

| 类别 | 类型 | 属性 |
|---|---|---|
| 基本类型 | `i8` `i16` `i32` `i64` `f32` `f64` `bool` `char` | **Copy** |
| 共享引用 | `&T` | **Copy**（可自由复制） |
| 可变引用 | `&mut T` | **Move**（独占：复制会破坏独占性） |
| 裸指针 | `*T` `*mut T` | **Copy**（不受借用检查跟踪） |
| 结构体 | `struct` | **Move**（除非全部字段 Copy 也不自动 Copy） |
| 枚举 | `enum` | **Move** |
| 数组 | `[T; N]` | **Move**（即使元素是 Copy——保持元素引用的单一所有权） |
| `void` | — | 无值 |

Copy 类型的赋值/传参是值拷贝；Move 类型是移动，移动后原绑定不可使用（见[所有权](./ownership.md)）。

## 基本类型

- 整数：`i8` `i16` `i32` `i64`（运行时宽度 8/16/32/64 位）
- 浮点：`f32` `f64`
- 布尔：`bool`（运行时 1 位，运算时扩展为 i32）
- 字符：`char`（**运行时是 i32**，存 Unicode 码点；无 char 算术，需 `as i32` 后运算）
- `void`：无值类型，仅用于函数返回

整数运算默认 `i32`；整数字面量类型为 `i32`，浮点字面量为 `f64`。

### never（uninhabited / bottom 类型）

`never` 是**没有任何值的类型**（bottom）。它的用途是描述「不会正常返回」的计算：

- 内置 `panic(&i8) -> never`（见[内置函数](./builtins.md)）。
- 用户可以显式把函数返回类型写成 `never`：`fn die(m: &i8) -> never { panic(m); }`。
- **兼容性**：`never` 类型的表达式可以出现在任何期望类型的位置，因为它不可能产生一个
  类型不符的值。已覆盖的位置：`ret`、实参、match 臂、`let` 初始化器、赋值、数组元素。
  反向不成立（其它类型不能当作 `never`）。除 `never` 之外没有放宽任何检查。
- **函数返回类型**：写成 `never` 的函数**必须发散**——编译期要求函数体至少含一个发散调用
  （`panic(...)`，或调用另一个 `never` 函数），否则报错。这是保守检查：它保证「某处会
  发散」，不证明「每条路径都发散」（完整路径分析会对 `while true { panic(...); }` 误报）。
- **变量类型**：`let x: never;` 合法（类型系统里它是 bottom），但绑定不可能持有值，
  因此**读取它是编译错误**。它不是日常写法。
- **不可达性**：同一语句序列中，`never` 调用之后的语句不可达。

> 注意：`never` 与 `void` 不同——`void` 在[基本类型](#基本类型)中表示「无值返回」，
> 而 `never` 表示「控制流不会到这里」。

## 引用类型

<grammar>
reference_type = "&" ["mut"] type
</grammar>

- `&T`：共享引用，只读。
- `&mut T`：独占可变引用。

- `&T` 是 **Copy**：可以自由复制、同时存在多份。
- `&mut T` **不是 Copy**：独占引用一旦可以复制，两份「独占」访问就同时存在，
  借用检查器的保证随之失效。`let b = a;`（`a: &mut T`）是**移动**，之后 `a` 不可再用。
  - **隐式重借用**：把 `&mut T` 传给另一个接受引用的函数/方法时不会消耗它——
    被调用方拿到的是**本次调用期间**的重借用（与方法接收者的临时借用同规则），
    调用结束后原引用仍可用：`fn g(p: &mut S)` 里连续 `g(p); g(p);` 合法。
  - 非 Copy 绑定必须在声明处初始化：`let r: &mut S;` 报 E3012。

类型兼容是**方向性**的（全部是安全方向，反向一律拒绝）：

| 从 | 到 | 说明 |
|---|---|---|
| `&mut T` | `&T` | 可变引用可被读取为共享引用 |
| `&T` | `*T` | 共享借用退化为只读裸指针 |
| `&mut T` | `*mut T` | 可变借用退化为可写裸指针 |
| `&mut T` | `*T` | 丢弃可变性 |
| `*mut T` | `*T` | 丢弃可变性 |

反向（`&T` 传给期望 `&mut T` 的参数、`*T` 当作引用）被拒绝。

## 裸指针类型

<grammar>
pointer_type = "*" ["mut"] type
</grammar>

- `*T`：只读视图；`*mut T`：可写。二者都是 **Copy**，且**不参与借用检查**：
  没有生命周期、没有独占性、没有悬垂检查。
- 用途是**堆缓冲的表示**：标准库的 `String` 用 `data: *mut i8` 持有 malloc 出来的块。
- 只能**索引**（`p[i]`，C 指针算术，**无越界检查**）与传值；没有指针算术、没有与整数的
  互转（cast 仍只支持基本类型之间），也没有通过指针访问字段。
- **不安全核心**：索引裸指针、以及把裸指针转回引用（内置 `__deref` / `__deref_mut`）
  只能出现在**标准库**里（否则 E3014）。这样语言其余部分是安全的：用户代码只能通过
  `String` 这类带边界检查的 API 使用堆。
- `*T` / `*mut T` **不能作为数组元素**（与引用元素同一条禁令）。
- 指针字段**不需要析构**：含有指针的结构体不会为它生成 drop glue。

引用语义（借用检查）见[借用检查](./borrow.md)。写穿规则：

- 通过共享引用写（`r.x = 5`，其中 `r: &T`）→ 编译错误「cannot assign through a shared reference」。
- 通过 `&mut` 引用写穿字段/元素（`s.data[i] = 'x'`）→ 允许（不改动 `s` 本身）。

## 数组类型

<grammar>
array_type = "[" type ";" integer_literal "]"
</grammar>

约束（编译期）：

- 尺寸必须是十进制整数字面量，且 `1 <= N <= 1<<20`（1048576）；空数组/`[T; 0]` 拒绝。
- 元素必须是 Copy 类型（`[T; N]` 本身仍是 Move）。
- 元素不能是引用或裸指针（`[&mut i8; 2]`、`[*mut i8; 2]` 均拒绝——间接层逃逸未支持）。
- **数组不能作函数参数或返回类型**（LLVM 数组非 first-class）；改用 `&[T; N]`。

运行时：

- 数组索引 `a[i]` 编译期发出 `i < 0 || i >= N` 检查，越界调用 libc `abort()`。
- 索引必须为 `i32`。
- 指针式索引（如 `s.data[i]`，`data: &mut i8`）**无长度检查**（无法知道长度）。

数组字面量 `[a, b, c]`：所有元素必须同类型，元素须 Copy 且非引用；空字面量 `[]` 拒绝
（无元素类型可推断）。`[v; N]` 是重复字面量：`v` 求值一次、复制 N 份，N 为字面量且
`1 <= N <= 1<<20`。数组字面量在**全局**位置仍被拒绝（全局初始化器必须是字面量）。

## 结构体

结构体是命名字段集合。字段默认私有（仅本结构体方法内可访问），`pub` 显式公开。
访问不存在的字段、对非结构体做成员访问都是编译错误。

## trait 与 Self

<grammar>
trait_type = identifier ["<" type_list ">"]
</grammar>

`trait` 声明方法契约。类型通过 `impl Trait for Type` 实现 trait。
`T: Trait` 是泛型约束。**`Self`** 类型在 trait 方法签名中表示「实现该 trait 的类型本身」，
在 `impl` 方法体中表示「被实现的结构体」。`Self` 只能出现在 trait/impl 上下文。

## 函数类型

函数类型（参数→返回）在编译器内部存在（`FunctionType`），支持**间接调用**
（函数指针：`let fp = foo; fp(x);`），但源码中**没有函数类型语法**——
函数指针通过函数名表达式隐式获得。

## 类型兼容与转换

- 赋值/传参要求类型兼容：同类型，或 `&mut T` → `&T` 宽化。
- **不存在隐式类型转换**；所有转换用 `as` 显式写出（规则见[运算符与类型转换](./operators.md)）。
