# 借用检查

<!-- grammar_name: borrow, search_name: 借用,借用检查,引用,NLL,生命周期 -->

Lis 的借用检查器在语义分析阶段（HIR）工作，保证引用不与其它引用/写入/移动冲突，
并拒绝悬垂返回。规则分三层：词法借用 → NLL（非词法生命周期）→ 悬垂/逃逸检查。

## 借用模型

- `&x`：共享借用（只读）。
- `&mut x`：独占可变借用（要求 x 可写）。
- 每个借用记录：根变量、路径（字段链）、可变性、创建语句、借用持有者。

路径重叠 = 前缀关系：`["a"]` 与 `["a","b"]` 重叠（祖先/后代）；`["a"]` 与 `["b"]` 不重叠
（不相交，可共存）；`[]`（整值）与任何字段重叠。

## 冲突矩阵

借用存活期间，以下操作与活跃借用冲突：

| 操作 | 与共享借用 `&` 冲突 | 与可变借用 `&mut` 冲突 |
|---|---|---|
| 创建 `&mut` | ✓（E4001） | ✓（E4001） |
| 创建 `&` | ✗ | ✓（E4002） |
| 写 / 移动 | ✓（E4003/E4004） | ✓ |
| 读（Copy） | ✗ | ✓（E4002，调用期间为预留时除外，见下） |

```lis
let r = &x;            // 共享借用
let s = &mut x;        // 错误:cannot borrow 'x' because it is already borrowed as mutable
```

错误码：E4001 借可变时已被借、E4002 借共享时已借可变、E4003 借用中写入、
E4004 借用中移动、E4005 借用已移动值、E4006 对不可变位置借可变、E4007 悬垂返回。

## 借用生命周期

### 临时借用（语句级）

函数调用的实参借用、方法接收者借用（`foo(&x)`、`x.m(&self)`）在**语句结束**时失效。

### 二相借用（调用期间的预留，2026-09-19）

方法接收者与**引用实参**在调用期间只是一次**预留（reservation）**：被调方在其余实参求值
完毕之前还没有碰过那个位置，所以在兄弟实参里**读**它、或对它取共享借用都是合法的。

```lis
s.set(s.n + 5);                     // ✓ 接收者已预留，实参读 s.n
code.patch(jz, code.count);          // ✓ 同上
vm_push(self, self.vars[arg]);       // ✓ 引用实参预留，另一个实参读 self 的字段
```

预留**不**放宽写与移动，它们仍然立刻冲突：

```lis
x.m(x);            // ✗ cannot move out of 'x' because it is borrowed
b(s, a(s));        // ✗ 第二个 &mut：already borrowed
s.n = take(s);     // ✗ 预留期间写（赋值目标在实参之后检查）
```

预留随**语句**结束（这些是临时借用），因此语句之外的判定完全不变。

### 变量借用（块级）与 NLL

`let r = &x;` 把借用**提升**为变量借用。默认存活到块末；NLL（非词法生命周期）按
**最后一次使用**（holder last-use）提前结束：

```lis
let br = &bc;        // br 的最后使用是 bv2
let bv = br.a;
let bv2 = br.a;
let bw = &mut bc;    // OK:br 的借用已在 bv2 结束(NLL)
bw.a = 9;
```

移动保持**保守**（不 NLL）：借用存活期间任何移动都被拒绝（防悬垂，与 Rust E0505 一致）。

### 借用移动值

对已移动的值（整值或部分字段）借用 → E4005。部分移动后借**不相交兄弟字段**允许：

```lis
let v = p.b;         // 移动 p.b
let r = &p.a;        // OK:不相交字段
```

### 字段精度

字段级借用按路径精确判定：`&p.a` 与 `&mut p.b` 共存；`&p` 与 `&p.a` 冲突（祖先/后代）。

**数组索引例外**：所有索引映射为通配路径 `[*]`——`a[0]` 与 `a[1]` 保守地视为重叠
（拒绝不相交元素借用；保持健全，精度留待后续）。

### 方法接收者

- 接收者借用先于实参登记（`x.m(x)` 的冲突能抓到）。
- `&mut self` 要求接收者是可变位置（E4006）。
- 引用型接收者直接传引用值（`&mut S` 可服务 `&self`；`&S` 不能服务 `&mut self`）。

## 写穿规则

- 通过共享引用写：`r.x = 5`（`r: &T`）→ 错误「cannot assign through a shared reference」。
- 通过 `&mut` 引用写穿字段/元素：`h.buf[0] = 5`（`buf: &mut [i32; 2]`）→ 允许
  （写的是被引用对象，不改持有者）。通过 `*T` 写元素 → 错误
  「cannot assign through a shared raw pointer」。
- 字段赋值（re-seat）要求根可变（修改结构体本身）。

## 隐式重借用（`&mut T` 不是 Copy 的配套）

`&mut T` 独占，因此**不能复制**；但把引用**转交**给别的函数/方法不该消耗它。
调用点对「引用型实参 → 引用型形参」自动做一次**临时重借用**：

```lis
fn g(p: &mut S) { p.v = 2; }
fn f(p: &mut S) { g(p); g(p); }   // 合法：两次调用各拿一次重借用
```

- 重借用的生命周期是**该语句**，与方法接收者的临时借用同规则；调用结束后原引用仍可用。
- 与接收者借用一样，重借用登记在实参自身的根位置上，冲突检查沿用同一套机制
  （`f(r, r)` 这类同一实参的双重可变借用仍然被拒绝）。
- 像借用检查器的其余部分一样，它**偏保守放行**：经由另一个别名到达同一被引用对象的冲突
  会漏报，而不是误拒。
- 裸指针（`*T`/`*mut T`）**完全不参与**借用检查：它是 Copy，没有生命周期与独占性。

## 悬垂返回检查（Stage 3：RefOrigin）

返回引用的来源被分类：`Local`（本函数栈帧）| `Param`（调用者）| `Global`（静态）| `Unknown`。

- 返回指向本帧的引用 → **E4007**：`cannot return reference to 'x': it does not live long enough`。
- 返回含引用字段的结构体，若字段指向本帧 → E4007。
- 安全模式：返回引用参数、`&self` 的字段、全局/字符串字面量、由参数/全局引用组成的结构体。
- 按值参数的引用字段：参数是拷入本帧的副本，指向它的引用同样悬垂 → 拒绝。

```lis
fn f() -> &i32 { let x = 5; ret &x; }        // E4007
fn f(p: &i32) -> &i32 { ret p; }             // OK:参数来源
fn get(self: &S) -> &i32 { ret &self.v; }    // OK:&self 字段
```

重赋值会刷新来源追踪：`let mut r: &i32 = &G; r = &x; ret r;` 拒绝（`&x` 是本帧）。

## 位置（place）与精度（2026-09-19）

借用检查比对的是**位置**，不是名字：`根 + 投影序列`，投影段有四种——字段名（`p.a`）、
**常量索引**（`a[0]`）、未知索引通配（`a[*]`）、解引用标记（`*`）。两条规则：

1. **常量索引是精确的**：`&mut a[0]` 与 `&mut a[1]` 不相交，两者可以同时存活并各自写穿；
   同一个索引（`&mut a[0]` 两次）仍然冲突。索引**不是编译期常量**时退回通配 `[*]`，
   它与任何索引段都重叠（无法知道值，只能保守）。
2. **解引用经别名表解析**：`let r = &mut x;` 记下 `r` 的来源是位置 `x`，于是 `*r` 就是 `x`，
   `(*r).a` 就是 `x.a`。这让穿透引用的借用进入同一套记账：`&mut x` 与 `&mut *r` 会互相冲突。

```lis
fn main() -> i32 {
    let mut a = [1, 2, 3];
    let p = &mut a[0];      // a[0]
    let q = &mut a[1];      // a[1]：不相交
    *p = 7; *q = 8;
    let i = 1;
    let r = &mut a[i];      // [*]：与上面两者都重叠
    ret 0;
}
```

### 重借用（`&mut *r`）与豁免链

穿透解引用的借用分两半：**指针本身**要可用，**所指位置**才被借走。

- 「指针可用」= 在指针的位置上登记一次**冻结**借用；正在被重借用的引用因此不能再被使用，
  也不能再重借用一次（`let s = &mut *r; let t = &mut *r;` → E4001，Rust 的 E0499）。
- 冻结与所指位置的借用都随 **holder 的最后一次使用**结束（NLL），所以
  `let s = &mut *r; *s = 5; ret x;` 合法。
- 通过引用访问时，它自身**派生链**上的借用全部豁免：`*s = v` 不会被 `s` 或 `r` 自己那次借用
  挡住（写穿自己的独占借用正是它的用途）。链由 `let s = &mut *r;` 记录（`r` 是 `s` 的"来源"），
  拷贝引用（`let q = s;`）会接上同一链。
- 派生链只在"通过该引用访问"时豁免：**其它**访问（`&mut x`、直接读 `x`、`*r` 在重借用存活期间）
  照常看到这些借用。

## 已知保守边界

- `let r = &call_返回的struct; ret r.v` 等嵌套结构体引用字段（source Unknown → 放行，漏报不误报）。
- **指针来源未知时不透明**：参数（`fn f(p: &mut T)`）或赋值覆盖过的引用没有别名记录，
  `*p` 只用「同一个引用表达式 = 同一个位置」这一条来判冲突——两个 `*p` 会冲突，但 `*p` 与
  调用者传进来的那个变量之间的联系看不到（由调用方保证）。
- **数组字面量的通配**：只有字面量整数索引是精确的；`a[i]`、`a[2 * k]` 都是 `[*]`。
- 返回借用不追踪：`let c = s.to_cstr(); drop(s); print_str(c)` 悬垂——编译器不跟踪返回借用，
  由调用方保证 owner 存活（见[标准库](./stdlib.md)的 String 文档）。
- 裸指针完全不检查：`*T` 的越界、悬垂（`__free` 之后继续用）与别名都不在借用检查器
  的职责范围内。它们被限制在标准库里（E3013/E3014），并记录在[已知限制](./limitations.md)。
