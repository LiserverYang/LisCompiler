# 借用检查

<!-- grammar_name: borrow, search_name: 借用,借用检查,引用,NLL,生命周期 -->

Lis 的借用检查器在语义分析阶段（HIR）工作，保证引用不与其它引用/写入/移动冲突，
并拒绝悬垂返回。规则分三层：词法借用 → NLL（非词法生命周期）→ 悬垂/逃逸检查。

## 借用模型

- `&x`：共享借用（只读）。
- `&mut x`：独占可变借用（要求 x 可写）。
- 每个借用记录：根变量、路径（字段链）、可变性、创建语句、借用持有者。

路径重叠 = 前缀关系：`["a"]` 与 `["a","b"]` 重叠（祖先/后代）；`["a"]` 与 `["b"]` 不重叠
（不相交，可共存）；`[]`（整值）与任何字段重叠。

## 冲突矩阵

借用存活期间，以下操作与活跃借用冲突：

| 操作 | 与共享借用 `&` 冲突 | 与可变借用 `&mut` 冲突 |
|---|---|---|
| 创建 `&mut` | ✓（E4001） | ✓（E4001） |
| 创建 `&` | ✗ | ✓（E4002） |
| 写 / 移动 | ✓（E4003/E4004） | ✓ |
| 读（Copy） | ✗ | ✓（E4002） |

```lis
let r = &x;            // 共享借用
let s = &mut x;        // 错误:cannot borrow 'x' because it is already borrowed as mutable
```

错误码：E4001 借可变时已被借、E4002 借共享时已借可变、E4003 借用中写入、
E4004 借用中移动、E4005 借用已移动值、E4006 对不可变位置借可变、E4007 悬垂返回。

## 借用生命周期

### 临时借用（语句级）

函数调用的实参借用、方法接收者借用（`foo(&x)`、`x.m(&self)`）在**语句结束**时失效。

### 变量借用（块级）与 NLL

`let r = &x;` 把借用**提升**为变量借用。默认存活到块末；NLL（非词法生命周期）按
**最后一次使用**（holder last-use）提前结束：

```lis
let br = &bc;        // br 的最后使用是 bv2
let bv = br.a;
let bv2 = br.a;
let bw = &mut bc;    // OK:br 的借用已在 bv2 结束(NLL)
bw.a = 9;
```

移动保持**保守**（不 NLL）：借用存活期间任何移动都被拒绝（防悬垂，与 Rust E0505 一致）。

### 借用移动值

对已移动的值（整值或部分字段）借用 → E4005。部分移动后借**不相交兄弟字段**允许：

```lis
let v = p.b;         // 移动 p.b
let r = &p.a;        // OK:不相交字段
```

### 字段精度

字段级借用按路径精确判定：`&p.a` 与 `&mut p.b` 共存；`&p` 与 `&p.a` 冲突（祖先/后代）。

**数组索引例外**：所有索引映射为通配路径 `[*]`——`a[0]` 与 `a[1]` 保守地视为重叠
（拒绝不相交元素借用；保持健全，精度留待后续）。

### 方法接收者

- 接收者借用先于实参登记（`x.m(x)` 的冲突能抓到）。
- `&mut self` 要求接收者是可变位置（E4006）。
- 引用型接收者直接传引用值（`&mut S` 可服务 `&self`；`&S` 不能服务 `&mut self`）。

## 写穿规则

- 通过共享引用写：`r.x = 5`（`r: &T`）→ 错误「cannot assign through a shared reference」。
- 通过 `&mut` 引用写穿字段/元素：`s.data[i] = 'x'` → 允许（写的是被引用对象，不改 `s`）。
- 字段赋值（re-seat）要求根可变（修改结构体本身）。

## 悬垂返回检查（Stage 3：RefOrigin）

返回引用的来源被分类：`Local`（本函数栈帧）| `Param`（调用者）| `Global`（静态）| `Unknown`。

- 返回指向本帧的引用 → **E4007**：`cannot return reference to 'x': it does not live long enough`。
- 返回含引用字段的结构体，若字段指向本帧 → E4007。
- 安全模式：返回引用参数、`&self` 的字段、全局/字符串字面量、由参数/全局引用组成的结构体。
- 按值参数的引用字段：参数是拷入本帧的副本，指向它的引用同样悬垂 → 拒绝。

```lis
fn f() -> &i32 { let x = 5; ret &x; }        // E4007
fn f(p: &i32) -> &i32 { ret p; }             // OK:参数来源
fn get(self: &S) -> &i32 { ret &self.v; }    // OK:&self 字段
```

重赋值会刷新来源追踪：`let mut r: &i32 = &G; r = &x; ret r;` 拒绝（`&x` 是本帧）。

## 已知保守边界

- `let r = &call_返回的struct; ret r.v` 等嵌套结构体引用字段（source Unknown → 放行，漏报不误报）。
- 数组索引路径 `[*]` 的精度损失（误拒不相交元素借用）。
- 返回借用不追踪：`let c = s.to_cstr(); drop(s); print_str(c)` 悬垂——编译器不跟踪返回借用，
  由调用方保证 owner 存活（见[标准库](./stdlib.md)的 String 文档）。
